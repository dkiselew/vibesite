# Web Docs

Welcome to the Web Docs system!

This document is a test page created to demonstrate the basic functionality of webdocs. Here you can save, update, share, rename, or delete your documents as stable links.

- **Create and edit markdown files**
- **Documents are rendered and served as HTML**
- **Share your content at a live stable link**

For more information, refer to the documentation or try uploading your own document.

Enjoy creating with webdocs!
