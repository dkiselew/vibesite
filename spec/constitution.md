---

## Что это

Web Docs — папка и адрес для документа, который уже собрал чужой ИИ. Генерация есть в Claude и аналогах. Мы не пишем страницу. Главная фича: эта папка может быть общей для организации. Один список, одни URL, один диск. Свой домен — рядом, не вместо папки.

Это не сайт, не CMS, не хостинг проекта, не чат, не замена Confluence, не замена документов в чате. Общая папка — не вики и не совместная каретка.

---

## Инварианты

1. **Документ = один HTML-файл = один URL.** Save = live. Отдельного Publish нет. Черновика нет: в списке лежит то, что откроет получатель.
2. **Имя файла = сегмент адреса** внутри workspace. Не случайный slug деплоя. `cv.html` живёт как `/cv` на субдомене workspace. Содержимое можно заменить, путь не меняется.
3. **URL документа:** `https://{workspace}.{host}/{name}`. Workspace — субдомен, имя — единственный сегмент пути. Apex `{host}` — приложение, не пространство документов. `https://{workspace}.{host}/` без имени — не индекс сайта.
4. **Папка — это продукт.** Список документов, не проекты и не деплои. Нет превью-карточек «сайтов», нет «last deploy». Папка workspace — одно пространство имён. Она может быть общей для организации: все члены видят те же документы и те же URL. Вложенные папки, вики и граф страниц — запрещены.
5. **Replace не меняет URL.** Duplicate создаёт новый документ и новый URL. Git человеку не показывается.
6. **MCP — диск документов, не CLI деплоя.** Нет tools и кнопок `publish`, `deploy`, `preview URL`. Агент пишет файл, в ответе — публичный URL. Человек шарит ссылку.
7. **Мы не пишем страницы за пользователя.** Своего ИИ, чата и мастера «сделай мне страницу» нет. Чужие чаты уже делают документ. Мы храним, отдаём и даём ими управлять. Каталог шаблонов (Stage 2) — не генерация: картинка для человека + спека для чужого ИИ по URL.
8. **Читать, не править.** Публичная страница — поверхность чтения. Нет каретки, комментариев, саджестов, `contenteditable`, «can edit».
9. **Один формат — HTML.** Нет markdown как source of truth, нет сборки, нет git в интерфейсе.
10. **Превью и есть документ.** Открыть из списка = та же страница, что по публичному URL (включая заголовки, CSP и плашку Free, если она есть).
11. **Публичная выдача не исполняет авторский JavaScript.** HTML — документ, не приложение. Иначе это чужой хостинг скриптов.
12. **Один документ не связан с другим роутингом.** Нет меню сайта, нет навигации между документами как у сайта. Ссылка внутри HTML может вести куда угодно — это содержимое файла, не наша IA.
13. **Stage 1 только.** Stage 2 (каталог шаблонов; правки на уже залитой странице) и свой чат — не реализовывать, пока этот инвариант не сняли отдельной датой. Общая папка организации — Stage 1, не Team «потом».
14. **Free закрывает петлю документа.** Сгенерировали → лежит в папке → шарится по стабильному URL → Replace по тому же адресу. Папку можно сделать общей. Свой домен — не замена этой петли.
15. **Общая папка = один диск.** Члены организации работают с тем же списком и тем же URL-пространством. Нет личных подпапок внутри workspace, нет «моих» и «чужих» документов в одной папке, нет правок страницы вдвоём. Приглашение даёт диск, не каретку.

## Запрещено добавлять

Пока этого нет в конституции, агент не имеет права «додумать»:

- редактор HTML / markdown / WYSIWYG / DevTools как фича
- второй source of truth (`.md` рядом с `.html`)
- git, ветки, commit, deploy, preview URL в UI или MCP
- совместное редактирование, комментарии, шаринг «can edit»
- вики, вложенные папки как база знаний, граф страниц
- многостраничный сайт, меню, роутинг между документами
- конструктор блоков, маркетплейс тем и мастер «сгенерируй страницу у нас»
- свой модельный чат и генерацию страницы внутри продукта
- шаблоны как обычные документы workspace (Rename/Replace не должны ломать чужие промпты)
- черновик отдельно от живого URL
- документы на apex вида `https://{host}/{name}` (workspace должен быть субдоменом)
- исполнение `<script>` и обработчиков событий автора на выдаче

## Объекты (только эти)

| Объект | Смысл |
|---|---|
| **Workspace** | Папка документов. Субдомен и пространство имён. Может быть общей для организации. |
| **Membership** | Связь аккаунта с workspace: owner или member. Не роль на документе и не «can edit» страницу. |
| **Document** | Один HTML-файл. Имя = путь `/name` на субдомене workspace. |
| **Версия** | Не история git. Только явный Duplicate: отдельный документ, отдельный URL. |

Нет Site, Project, Deployment, Collection, Team, Org как сущностей продукта. Организация = общая папка (workspace + memberships).

**Stage 2, не объект Stage 1.** Template живёт на apex (`https://{host}/templates/{id}`), не на субдомене workspace. Не Document: нет Rename/Replace как у файла автора.
