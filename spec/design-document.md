# Web Docs

**Слоган:** Web Docs: Общая папка для ваших AI-документов. Из чата — в дело.

**Дата:** 2026-09-18
**Обновлено:** 2026-09-21

Web Docs — это удобное хранилище для документов, которые вы генерируете с помощью нейросетей (ChatGPT, Claude, Cursor и других).

Представьте себе общую папку для всей вашей команды. Вы просите ИИ написать коммерческое предложение, резюме или отчет, а затем просто сохраняете готовый HTML-файл в Web Docs. Документ получает красивую, постоянную ссылку, которой легко поделиться с клиентами или коллегами. Мы не создаем еще одну нейросеть для генерации текста — мы даем удобное место, где эти сгенерированные документы будут жить и работать на вас.

---



## В чем суть проекта?

**Что это такое?** Это сервис для хранения одиночных HTML и Markdown-документов. У каждого документа есть свой постоянный URL. Это не конструктор сайтов, не CMS и не замена вашему любимому ИИ.

**Зачем это нужно?** Нейросети отлично справляются с созданием контента: инвойсов, планов, статей, резюме. Но сгенерированный документ остается «запертым» в истории чата. Его неудобно искать, сложно показать коллегам, у него нет красивого адреса, и он находится на чужом сервере.

**Что мы предлагаем?** Web Docs забирает документ из чата и делает его по-настоящему вашим. Вы получаете единое пространство (общую папку) для всей команды. Коллега сохраняет файл — и он тут же появляется у всех, доступный по постоянной ссылке. Если вы обновили документ, ссылка останется прежней.

**Для кого это?** Для студий, агентств, HR-специалистов и фрилансеров, которые уже активно используют ИИ для создания рабочих материалов и хотят удобно их хранить, делиться ими и работать совместно.

**Для чего это НЕ подойдет?** Мы не делаем многостраничные сайты, базы знаний (как Notion или Confluence) или инструменты для одновременного редактирования текста (как Google Docs). Наша задача — красиво подать готовый результат.

## Примеры использования (Use cases)

Вместо того чтобы делать десятки мелких сайтов, вы просто создаете документы и кладете их в нужную папку. У всех документов один скролл и один URL.

1. **Документ из переписки с ИИ.** Вы долго обсуждали проблему с ChatGPT или Claude. Вместо того чтобы оставлять результат в истории чата, вы сохраняете его в Web Docs. Теперь это официальный документ вашей команды с постоянной ссылкой.
2. **Резюме (CV).** Красиво оформленная страница с вашим опытом. Обновили навыки? Просто заменили файл (Replace), а ссылка в соцсетях осталась рабочей. Нужна версия под конкретную вакансию? Сделали копию (Duplicate).
3. **Коммерческое предложение.** Отправляете клиенту смету и план работ. Документ лежит в папке вашей студии, выглядит профессионально и при необходимости легко обновляется.
4. **Материалы после встречи (Leave-behind).** Краткая выжимка договоренностей, пара схем и контакты. Идеально, чтобы отправить фоллоу-ап после созвона.
5. **Прайс-лист.** Аккуратная страница с вашими тарифами и условиями. Выросли цены? Просто обновите файл.
6. **Кейс проекта.** Рассказ об одной успешной задаче с метриками и отзывами. Отличный формат, чтобы прикрепить к коммерческому предложению.
7. **Регулярный отчет.** Ежемесячная сводка для клиента о проделанной работе и достигнутых результатах.
8. **Спецификация продукта (Datasheet).** Одностраничное описание вашего продукта или услуги с техническими характеристиками для партнеров.
9. **Закрытое приглашение.** Страница мероприятия с адресом, программой и списком гостей. Если время изменилось, вы просто обновляете документ по той же ссылке.
10. **План поездки.** Маршрут, брони и контакты для отпуска или командировки, собранные нейросетью и доступные по одной ссылке всем участникам.
11. **Памятка для гостей (Welcome-лист).** Код от Wi-Fi, инструкция к кофеварке и адреса ближайших магазинов для тех, кто арендует вашу квартиру.
12. **Меню ужина.** Красивая карточка с блюдами и винами для гостей вашего мероприятия.
13. **Хранилище для внутренних AI-агентов (Enterprise).** Крупные компании создают собственных агентов (custom GPTs, внутренние тулы), которые генерируют код, аналитику или документацию. Web Docs (в self-hosted версии) становится безопасным, изолированным хранилищем внутри контура компании, куда агенты складывают артефакты через MCP, не сливая данные во внешний мир.
14. **Автоматизированные LLM-пайплайны.** Скрипты, которые каждую ночь собирают данные, анализируют их с помощью LLM и генерируют отчеты или дашборды. Вместо того чтобы настраивать S3, CloudFront и писать скрипты деплоя, пайплайн делает один API-вызов в Web Docs и мгновенно получает публичную (или защищенную паролем) ссылку для отправки в Slack.

## Главные принципы

1. **Сохранил — значит опубликовал.** У нас нет сложных процессов деплоя или статусов «черновик». То, что лежит в папке, сразу доступно по ссылке.
2. **Имя файла — это адрес.** Файл `cv.html` будет доступен по адресу `/cv`. Все просто и предсказуемо. Завтра путь будет тем же, даже если содержимое изменится.
3. **Папка — основа всего.** Это ваше рабочее пространство. Вы можете создать общую папку для всей компании, где каждый сотрудник будет видеть актуальные документы.
4. **Удобное обновление.** Если вы загружаете новый файл с тем же именем (Replace), содержимое обновляется, а ссылка остается прежней. Если хотите сохранить старую версию, просто сделайте копию (Duplicate).
5. **Идеально для ИИ-агентов (MCP).** Нейросети могут напрямую читать и сохранять документы в вашу папку. Вы попросили ИИ составить отчет, и он тут же появился у всех коллег.
6. **Мы не пишем тексты, мы их храним.** Мы не конкурируем с ChatGPT или Claude. Они создают контент, а мы даем ему удобный дом.
7. **Создано для чтения.** Это не Google Docs, где несколько человек одновременно редактируют текст. Наши документы предназначены для того, чтобы их красиво презентовать и удобно читать.
8. **Экспорт в PDF.** Любой документ можно скачать в формате PDF в один клик. Идеально для отправки по почте, сохранения в архив или печати.

## Как это устроено (Объекты)

- **Рабочее пространство (Workspace):** Ваша главная папка. Пространство имен для ссылок. Может быть личной или общей для всей компании.
- **Участники:** Вы можете пригласить коллег (owner/member), и у вас будет единый диск с документами.
- **Документ:** HTML или Markdown-файл. Его имя становится частью ссылки (без `.html` или `.md`). Если вы загружаете `.md` файл, при открытии ссылки он автоматически отрендерится в красивую HTML-страницу по нашему встроенному шаблону.
- **Версия:** Вы всегда можете сделать снимок документа (Duplicate), чтобы сохранить его текущее состояние как отдельный файл с новой ссылкой.

## План развития: Этап 1 (Текущий фокус)

На первом этапе мы фокусируемся на базовом, но самом важном сценарии: вы берете готовый HTML или Markdown-документ из нейросети и кладете его в папку со стабильным адресом. Эту папку можно расшарить на команду. Свой домен пока не подключаем.

**Как добавить документ?**

- Просто перетащить файл (Drag & Drop) или вставить код в интерфейс.
- Попросить ИИ-агента (например, в Cursor) сохранить файл напрямую через MCP.

**Техническая гигиена:**

- Страница открывается как есть, по постоянному пути.
- Поддерживаем красивые превью для ссылок (OG-теги берутся из HTML).
- В целях безопасности мы не исполняем произвольные `<script>` из загруженных файлов на публичной выдаче. Документ должен оставаться документом, а не превращаться в веб-приложение.



### Модель монетизации

**Бесплатно (Free):**
Базовые функции будут бесплатными: создание папок (в том числе общих), загрузка документов (HTML и Markdown), автоматический рендеринг `.md` файлов в красивый HTML, скачивание любого документа в формате PDF, обновление файлов (Replace/Duplicate) и стабильные ссылки на нашем домене. Лимиты щедрые — этого достаточно, чтобы полноценно работать и привыкнуть к сервису.

**Платно (Pro):**
Платные функции нужны тем, кто хочет полного контроля над брендом. Оплата берется за пользователя, а не за количество документов.

- **Свой домен:** Документы будут открываться по вашему адресу (например, `offer.studio.com/acme`).
- **Удаление плашки Web Docs:** Документ выглядит на 100% вашим.
- **Приватность:** Установка паролей на документы или скрытие от поисковиков.
- **Аналитика:** Возможность узнать, когда открыли ссылку.
- **Срок жизни ссылки:** Автоматическое удаление документа через заданное время.

**Enterprise (Self-hosted):**
Для корпоративных клиентов, которым критична безопасность данных и интеграция с внутренними AI-пайплайнами.

- **Развертывание в закрытом контуре:** Установка Web Docs на серверах компании (on-premise или private cloud).
- **Изоляция данных:** Внутренние AI-агенты сохраняют артефакты без риска утечки коммерческой тайны.
- **API для автоматизации:** Интеграция с CI/CD и кастомными LLM-пайплайнами для массовой генерации отчетов.
- **SSO и управление доступом:** Интеграция с корпоративными системами авторизации.

**Критерий успеха Этапа 1:** Несколько организаций активно используют общие папки и регулярно обновляют документы (Replace) по одним и тем же ссылкам. Пока этого нет — к Этапу 2 не переходим.

## Планы на будущее: Этап 2 (Только после успеха Этапа 1)

- **Каталог шаблонов:** Готовые красивые структуры (CV, оффер, отчет) со спецификациями для ИИ. Вы даете нейросети ссылку на шаблон, и она генерирует документ по нужным правилам.
- **Правки прямо на странице:** Возможность слегка подредактировать текст загруженного документа без необходимости возвращаться в чат с ИИ и перегенерировать весь файл. Главное при этом — не превратиться в перегруженный редактор.
- **Версионирование (History):** Полноценная история изменений документа. Возможность посмотреть, как выглядел документ неделю назад, сравнить версии и откатиться к предыдущему состоянию без необходимости делать ручные копии (Duplicate) на каждый чих.
